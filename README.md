# SpeakUp

SpeakUp is an AI-powered speaking practice platform designed to help users improve communication skills through guided speaking exercises, speech analysis, personalized feedback, and progress tracking.

## Features

### Current
- React frontend
- Express backend
- PostgreSQL database integration (planned)

### Planned
- Daily Speaking Journal
- Impromptu Speaking Practice
- Mock Interviews
- Mock Thesis and Project Defenses
- Pageant Q&A Simulation
- Speech Recording
- AI-Powered Feedback
- Progress Analytics Dashboard

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL
- Supabase

### AI Services
- OpenAI API
- Whisper API
